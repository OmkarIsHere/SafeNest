# SafeNest - Family Location Tracking App

SafeNest is a family tracking app designed to provide real-time location tracking, enhanced safety features, and seamless communication among family members.

## Screenshots
![screenshot](images/screenshot.png)

## 📌 Features

### 🚀 Real-Time Location Tracking

- Allows family members to monitor each other’s real-time locations on an interactive map.
- Ensures peace of mind by making loved ones' whereabouts accessible at any time.

### 🔔 Notifications and Alerts

- Send timely updates about family member movements or unexpected location changes.
- Keeps families informed and enables quicker responses in emergencies.

### 🏠 Profile and Nest Management

- Users can create and join family Nests, share invitations, and manage profiles (including profile images).
- Simplifies managing family groups and ensures a seamless experience for all members.

### 🔒 User Privacy and Security

- It implements encrypted data transfer and secure login mechanisms.
- Ensures user data protection and fosters trust among family members.

## 🎯 Objectives & Scope

✅ **Seamless Real-Time Location Tracking**

- Monitor family members' locations with precision, enhancing safety and accessibility.

✅ **Enhanced Family Coordination**

- Features like geofencing and group notifications help families stay aligned during outings and emergencies.

✅ **User-Friendly Experience**

- Simple, intuitive interface designed for users of all ages, including voice commands and guided tutorials.


## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** XML
- **Backend:** Firebase (Firestore, Authentication, Cloud Messaging)
- **Google Services:** Google Maps API, Activity Recognition API
- **Database:** Firebase Realtime Database (for real-time storage)
- **Security:** Firebase Authentication

## 📱 Installation Guide

1. Clone the repository:
   ```
   git clone https://github.com/OmkarIsHere/safenest.git
   ```
2. Open the project in Android Studio.
3. Ensure you have the latest Kotlin and Gradle versions installed.
4. Configure Firebase by adding google-services.json to the app/ directory.
5. Build and run the app on an emulator or physical device:
    ```
   ./gradlew assembleDebug
    ```
## 📖 Usage
1. Sign Up & Create a Nest: Register and invite family members to your Nest.
2. Enable Location Permissions: Allow the app to access your real-time location.
3. Track & Stay Updated: View family members' locations and receive alerts.
4. Customize Privacy Settings: Control who can see your location.
